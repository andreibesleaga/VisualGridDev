# ADR-0002: arc42 for narrative, C4 for structural views

## Status

Accepted

## Date

2026-09-12 (recorded retroactively)

## Context

A specification of this size needs a predictable structure, or readers cannot
find anything and authors duplicate each other. Several established templates
exist: arc42, the 4+1 view model, the C4 model, and ISO/IEC/IEEE 42010.

These are not mutually exclusive. arc42 is a document structure; C4 is a diagram
notation. The specification already uses both, plus PlantUML as the source format
for diagrams.

## Decision

Use **arc42** as the narrative structure for the architecture description, and
**C4** as the notation for structural diagrams. Store diagram sources as PlantUML
so that diagrams are reviewable and diffable, and commit rendered SVG for
readers who do not render PlantUML.

## Consequences

**Positive.** A reader familiar with either template can navigate immediately.
Diagrams become reviewable artefacts rather than opaque images. Separate arc42
documents create natural homes for the sections that would otherwise bloat the
master specification.

**Negative.** Two structures in one repository means an author must decide which
one owns a given statement, and the boundary is not always obvious. The `arc42/`
directory in this repository contains several near-empty stubs, which suggests
the template was adopted before there was content to fill it. That is an
outstanding debt, recorded as item 7 in the open questions of
[PROJECT_STATUS.md](../../PROJECT_STATUS.md).

**Obligation.** PlantUML source and rendered SVG must not drift. A build check
should regenerate the SVG and fail on a difference.

## Alternatives considered

- **C4 only.** Rejected: C4 is a diagramming model, not a document structure;
  there is nowhere in it for quality goals, risks, or decisions.
- **4+1 views only.** Rejected: less familiar to the modern tooling ecosystem and
  weaker for non-functional requirements.
- **ISO/IEC/IEEE 42010 only.** Rejected: correct but heavyweight for a draft, and
  it prescribes no concrete document outline.
- **No template.** Rejected: the specification's size makes ad-hoc structure
  unworkable.
